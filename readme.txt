📞 NOMOR DARURAT PERBAIKAN:
==========================
Jika ada masalah, cek ini dulu:

❌ GAMBAR TIDAK MUNCUL?
   → Pastikan nama file sama persis
   → Contoh: project1.jpg (huruf kecil semua)
   → Ukuran file maksimal 1MB per gambar

❌ LINK TIDAK BEKERJA?
   → Pastikan semua file HTML ada di folder sama
   → Cek apakah ada file index.html, style.css

❌ WEBSITE TIDAK RESPONSIVE DI HP?
   → Pastikan meta viewport ada di <head>
   → Test di browser Chrome/Edge/Firefox

❌ FORM TIDAK MENGIRIM?
   → Form hanya simulasi, akan buka WhatsApp/Email
   → Pastikan terhubung internet
   → Pastikan ada aplikasi WhatsApp/Email di device
